Acorn is a fully autonomous securities trading system using the IB Gateway from Interactive Brokers and ChatGPT as its brain.
Acorn uses Telegram to interface with the user, allowing the user to control the system from anywhere.

This project is still under construction.

In the future
- Configurable and containerized with the IB Gateway to allow for deployment anywhere
- Unit tests covering all code paths
- More scheduled wake ups/wake up for emergency events triggered
- More order types/markets/security types for Acorn to use
- Documentation for how to set up/deploy
